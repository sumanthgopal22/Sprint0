# Sprint0

This program implements simple move functions for the character Link from The Legend of Zelda. It includes played movement animations for forward, backward, left, and right directions.
Using WASD to move Link with the keyboard, you can also use the mouse left click, right click, scroll wheel up, and scroll wheel down to move Link using the mouse.

I used the Monogame ([docs.monogame.net/articles/index.html](https://docs.monogame.net/articles/index.html)) tutorial to help come up with this code.
